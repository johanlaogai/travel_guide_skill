# Checklists：行前、行李与紧急信息

## 行前 7 天

- [ ] 证件：身份证/护照/签证/港澳台通行证（有效期、签注）
- [ ] 交通：往返票、值机/选座、行李额、车站/机场到酒店
- [ ] 住宿：确认入住/退房、取消政策、地址、前台电话
- [ ] 预约：博物馆/观景台/餐厅/演出；放票时间、实名规则
- [ ] 天气：16 天内预报、台风/暴雨/高温预警
- [ ] 保险：医疗/行李/延误；保单号离线保存
- [ ] 支付：现金、银行卡、移动支付、境外卡/汇率
- [ ] 网络：漫游/eSIM/当地卡、离线地图
- [ ] 健康：常用药、处方、过敏信息、医保
- [ ] 工作/家庭：请假、宠物/老人安排、紧急联系人

## 行李

- 证件/钱包/钥匙/手机；
- 充电器/充电宝（随身，不托运）/转换插头；
- 常用药/创可贴/口罩；
- 按天气：伞/雨衣/防晒/外套/好走的鞋；
- 水杯/纸巾/湿巾；
- 带娃：尿布/零食/玩具/推车；
- 带老人：常用药/病历/眼镜/拐杖；
- 摄影：电池/存储卡/防水袋。

## 紧急信息

- 中国：报警 110，急救 120，火警 119；
- 境外：查当地紧急电话 + 中国使领馆；
- 酒店地址/电话（离线截图）；
- 保险救援电话/保单号；
- 同行人联系方式（公开版删除）；
- 过敏/血型/常用药（必要时）。

## 途中

- 每天出门前看天气/闭馆公告；
- 重要预约提前 15 分钟到；
- 保留纸质/离线备份；
- 不把护照和钱包放一起；
- 夜间少走偏僻路段；
- 遇到罢工/封路/暴雨，优先安全，改行程。

## 公开分享

- `--public` 脱敏；
- 删除：电话、邮箱、证件、订单号、房号、车牌、二维码；
- 紧急联系人清空；
- 同行人姓名用昵称/首字母；
- 分享前自己再读一遍。
