# Delivery：构建、验收与分享

## 构建

```bash
node bin/travel-guide.mjs check --trip <trip.json> --strict
node bin/travel-guide.mjs build --trip <trip.json> --out <dir> [--public]
```

产物：

- `index.html`：单文件交互页；
- `itinerary.md`：聊天/文档版；
- `sources.md`：来源台账；
- `trip.ics`：日历；
- `build-receipt.json`：hash/覆盖率/警告。

## 浏览器验收

用 DSH 的 `bcdp_*` 打开 `file://.../index.html`。

### 桌面

- [ ] 控制台无错误；
- [ ] 首屏 hero、日期、人数、预算正常；
- [ ] 切天（全部/Day 1..N）；
- [ ] 类型筛选 + 搜索 + 重置；
- [ ] 地图缩放/拖拽/点 marker 联动卡片；
- [ ] 预算环形图/分类条；
- [ ] 行李/预约清单勾选，刷新后保持；
- [ ] 来源筛选；
- [ ] 明/暗主题；
- [ ] 打印预览（展开所有天）；
- [ ] 下载 ICS，能被日历打开。

### 移动（375×812）

- [ ] 无横向滚动；
- [ ] 日期 tabs 可横向滑；
- [ ] 地图不遮挡文字；
- [ ] 卡片/按钮可点；
- [ ] 打印不是主要场景。

### 内容

- [ ] 示例/公开版 banner 正确；
- [ ] 每条锚点/餐饮有来源徽章；
- [ ] 没有“官方”字样但来源是 UGC；
- [ ] 未核实项红色/待核实；
- [ ] footer 归属完整；
- [ ] 没有 Key/电话/订单号。

## 分享

- 公开版：`--public`，再人工检查；
- 聊天里给 3–5 行摘要 + 文件路径；
- 不要贴整份 HTML 源码；
- 不要承诺实时导航/下单；
- 提醒动态信息可能变化。

## 交付话术

```
已生成：<out>/index.html
摘要：3 天 2 晚，西关—珠江新城—白云山；每天 2–3 个锚点。
预算：¥2,050–3,050/2 人（不含大交通，示例）。
最需要提前：广东省博物馆预约、广州塔登塔时段。
来源：官方 N / OSM M / 预报 K；未核实项见 HTML 顶部。
```

## 失败时

- `check` 失败：先修硬错误，不要 `--allow-unverified` 糊弄正式行程；
- 构建失败：看错误行，不要手改产物；
- 浏览器打不开：检查 `file://` 路径、CSP、控制台；
- 地图空白：检查锚点经纬度/WGS84；
- ICS 打不开：检查 UTC 时间/换行；
- 分享泄露：立即撤回，重新 `--public` 构建。
